# SR

Retail business management system for **SR**, a single Kenyan retail shop: inventory with weighted-average cost, landed-cost stock-in, pricing engine with price floors, POS, customer credit, expenses, cash-ups and a profitability dashboard.

- `backend/` — FastAPI + SQLAlchemy + SQLite (Python via `uv`)
- `frontend/` — Next.js dashboard (tabs: Available Stock, Add Stock, …)
- `retail-management-system-spec-and-design.md` — functional spec & system design (source of truth)

How to run, and the design invariants, are in `CLAUDE.md`.
